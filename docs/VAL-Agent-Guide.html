V-Agent user guide

How to install, use, extend and look after your local agent.

Your agent, your models, your PC

A local-first AI agent for Windows

V-Agent runs GGUF models on your own computer (Strata, Strata Rust, llama.cpp or Project Maya), or uses an OpenAI- or Claude-compatible API, and gives them real tools: files, commands, web search, a browser and MCP servers. Every action follows the access and approvals you choose. Nothing leaves your PC unless you connect an API or let a tool go online.

Getting started 01

Install. Run V-Agent_<version>_x64-setup.exe. No administrator rights are needed. The program goes to %LOCALAPPDATA%\Programs\V-Agent and your chats, settings, engines and models to %LOCALAPPDATA%\V-Agent-Data. If Windows shows "Windows protected your PC", choose More info → Run anyway, only for installers from the official GitHub releases.

Choose a language. The installer offers the 14 interface languages; you can change it later in Settings → General.

Follow the tour (optional). It shows each part of the window and helps you pick an engine for your hardware or connect an API. You can repeat it from Settings.

Add a model. Open Models in the sidebar: download a GGUF from Hugging Face, or use Models on this PC to bring in models you already have. With an API, connect it and its models appear in the list.

Load it and chat. Pick the model next to the message box and press Load model. Then write your message and press Enter.

The window 02

Sidebar

New chat, a temporary chat (the ghost button), your Recent and pinned chats grouped by date, Projects, Extensions and Models.

Message box

+ attaches text files and images (images need a vision model), and you can also paste or drop them. Below it: the model, the thinking effort, the agent mode, access and approvals, and the globe for web search.

Replies

Thinking, each tool call with its result, the files the agent wrote (open them with one click), speeds measured by the engine, and actions to copy, regenerate or edit.

Settings

The gear opens Settings: General, Appearance, Message box, Tools, Market, Plugins, System and engines, and History. A search box finds any setting.

Modes, access and approvals 03

Three separate choices decide what the agent may do. All three are enforced by V-Agent's core, not only by the interface.

Agent mode: which tools it has

ModeTools
ChatConversation only, with optional web search and page reading (the globe). No files or commands.
LightEssential file, document, web and command tools; every command asks first.
StandardFiles, web, console, HTTP and Hugging Face tools you enable.
FullAlso desktop control and an elevated administrator helper, when you turn them on.

Access: where it may work

  • Sandbox (default): each chat has its own folder, and commands run in an isolated Windows process without network access.
  • Project: a folder you choose for a chat (the No project button above the message box).
  • Whole computer: files anywhere and normal commands. Choose it only when you need it.

Approvals: when it asks

  • Ask for approval: every tool or internet access is confirmed (reads inside the chat's folder run).
  • Confirm changes: reads run; writes, commands and unknown actions ask.
  • Automatic: the tools you enabled run without asking.
When the agent asks, you can allow once, allow always in this chat, or deny. After a denial it stops and asks how to continue. The agent can also ask you a question in the middle of a task; you can answer or let it decide.

Models 04

Download from Hugging Face

In Models, search Hugging Face and see how each quantization fits your GPU and RAM. Downloads are checked against their published SHA-256 and added to the list automatically. They go to V-Agent-Data\models\<creator>\<model>, or to a folder you choose.

Models on this PC

V-Agent finds the GGUF files you already have: LM Studio's folder, Unsloth Studio, the Hugging Face cache and any folder you add with Add folder…. Each model is shown in its real folder. Importing a list takes seconds: the files are not copied, and the settings those apps saved (sampling, context, KV cache, template) come with them. You can also move models into V-Agent's models folder; a different file with the same name in the destination is never overwritten.

Import and export

Under the model selector, Import & export saves a model's settings to a file, or sends them to LM Studio and Unsloth Studio.

Per-model settings

  • Context: how much text the model keeps in mind. Changing it on a loaded model reloads it.
  • KV cache: fewer bits use less memory; only the formats the engine and model support are shown.
  • Vision: add an mmproj file (llama.cpp) to send images.
  • Draft model: a small model that speeds up generation (speculative decoding).
  • Engine options: the options the installed engine lists (threads, expert placement and more).
Before loading, V-Agent estimates weights, KV cache and the memory it can reclaim, and while a reply runs it shows the speeds the engine itself reports.

Engines and APIs 05

Choose the engine in the Engine card (tabs This PC and APIs). Official engine builds are installed, updated, rolled back or removed in Settings → System and engines; each engine can also point to an executable you built yourself. Unload the model before updating an engine.

  • Your own MCP servers: add them in Settings → Tools or from the Market. They run outside the sandbox, so they can be turned on only with whole-computer access.
  • Plugins: instructions and ready-made prompts (commands) you install as local folders; they never run code.
  • Persistent instructions: write them in Settings → General (saved as AGENTS.md in your data folder). A project's own AGENTS.md is added for chats in that project.

Chats and files 07

  • Working folder: each chat has its own folder (Open Sandbox folder shows it). Files the agent writes appear under its reply and open with one click.
  • Temporary chats: never written to your history. Their folder is removed when you leave the chat; Save chat keeps the chat and its files.
  • Drafts: if a long file write is interrupted, what arrived is kept, and the agent (or you) can continue from it instead of starting again.
  • File history: each change the agent makes keeps the previous version (the last 100 per file), and you can restore any of them.
  • Compress context: when a long chat nears the model's limit, older turns can be summarized; the original messages stay in the chat.
  • Branches: editing a message or choosing another version of a reply starts a branch, so nothing is lost.
  • History: export or import all chats in Settings → History.

Where things are 08

Program folder

Data folder (back it up to keep everything)

%LOCALAPPDATA%\V-Agent-Data\

  versions\              earlier versions of files the agent changed

  AGENTS.md              your persistent instructions

  credentials\           API keys, encrypted with Windows DPAPI

Uninstalling keeps the data folder unless you tick Delete the application data. Updating never touches it.

Updates and privacy 09

V-Agent tells you when a new version is out, shows its notes, downloads it when you choose and installs it with Install and restart. Small fixes to tools can also arrive as minor updates. Every installer and minor update is checked against the maintainer's Ed25519 signature before it is used.

There is no account, no telemetry and no analytics. V-Agent goes online only to check updates, install engines, use an API you connected, or when a tool you enabled needs it (web search, page reading, HTTP, browser, Hugging Face, your MCP servers).

Troubleshooting 10

What you seeWhat to do
A model does not loadOpen the load diagnostics shown in the error; try a smaller context or a lighter KV cache, or another engine. Logs are in V-Agent-Data\logs.
"The private port 19383 is busy"Another program uses the engine port. Close it (V-Agent never stops a process it did not start) and load again.
An engine or app update is refusedUnload the model first, then update.
Commands are disabledIn Sandbox, commands need the isolated runner; otherwise choose whole-computer access for that chat.
The model only thinks and never answersLower the thinking effort, or ask for the task in parts.
Windows warns about the installerIt is not signed with a paid Microsoft certificate yet. Compare its SHA-256 with v-agent-update.json on the same release.
